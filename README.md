# 薰风斋 · 宋代点茶研习所（中国风静态站点）

一个纯静态的中国风网站，内容依据网络公开资料整理。零依赖、零构建，双击 `index.html` 即可打开。

## 文件结构

```
index.html        首页：斋记 / 造汤席点 / 七汤点茶法 / 茶器节选 / 研习 / 斋主 / 著作 / 到访
dian.html         点茶：工序八事 / 七汤详解（原文＋今释）/ 斗茶与茶百戏 / 东渡
qi.html           茶器：《茶具图赞》十二先生全图 / 建盏三品 / 器之复原
zhai.html         斋主观合小传 / 著作 / 斋中事纪 / 到访
assets/css/style.css   全部样式（宣纸底纹、朱砂、黛青、建盏黑釉配色）
assets/js/main.js      导航、滚动进场、七汤沫饽交互
.claude/launch.json    本地预览配置（Claude Code 用）
```

## 本地预览

任选其一：

```bash
python3 -m http.server 8777
```

然后打开 http://localhost:8777 ；或直接双击 `index.html`。

## 设计说明

- 配色：宣纸米白 `#f2ece0`、墨 `#1f1c19`、朱砂 `#9c342a`、黛青 `#34504b`、赤金 `#a8874f`、建盏黑釉 `#17130f`
- 字体：系统衬线（Songti SC / STSong / SimSun），标题竖排，落款用印章
- 图形：全部为手写 SVG 线描（茶盏、汤瓶、茶筅、十二先生等），无外链图片，离线可用
- 动效：首屏落字、沫饽浮动与汤气、滚动淡入、七汤盏中沫饽随悬停渐生
- 响应式：≤700px 首屏改为横排、器物网格两列
